# Live contract probe

[`isolated-world-fetch/`](./isolated-world-fetch/) is a throwaway, unpacked extension.
Run it in a signed-in ChatGPT conversation to record the current DOM structure and
whether a packaged content script can read the authenticated conversation response.
It is not included in the production build. Record only the redacted result in
[docs/phase-0-findings.md](../docs/phase-0-findings.md).
